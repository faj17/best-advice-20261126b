One sentence about the best advice the writer ever got. The night before his first job, his father told him never to sign anything he had not read twice — and he has not skipped a line since. It is a small memory with a rule inside it: a warning given once, kept for life.

## How it works

`main.py` builds the sentence from three parts, keeps two rejected drafts beside it with the reason each one lost, and checks the winner before writing it: exactly one sentence, 1–200 characters, no trailing newline. The checked line goes to `/output/entry.txt`.

```sh
python3 main.py
```
